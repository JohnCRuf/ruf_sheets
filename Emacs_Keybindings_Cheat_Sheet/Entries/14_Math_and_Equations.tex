\subsection{Snippets that fire inside math}
Typed inside \fn{\kbslash( \dots \kbslash)} or \fn{\$ \dots \$}, these expand as
you type (laas).
\begin{keys}[2.6cm]
\krow{;E \ ;V \ ;C \ ;P}{$\mathbb{E}$, Var, Cov, Pr}
\krow{;a \ ;b \ ;g}{Greek letters}
\krow{;;d}{$\partial$ \quad \key{;8} $\infty$}
\krow{x1}{$x_1$ \quad \key{x/} a fraction}
\krowx{\korr{sr}{cb}}{squared / cubed}
\krow{argmin \ argmax}{operators with a subscript slot}
\krow{plim \ ols}{$\operatorname{plim}$, $\widehat{\beta}_{\mathrm{OLS}}$}
\end{keys}
Equations render to images when point leaves them (org-fragtog). Move back into
one to edit the source again.
